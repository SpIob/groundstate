# Groundstate

An AI-orchestrated pipeline that screens materials for efficient, theoretically grounded alternatives to current energy resources. V1 covers Li-ion battery cathodes. Built by Mico — an independent AI enthusiast, not an energy scientist — as a computational screening tool, not a source of validated experimental results.

This repo is built and run by a small team of AI agents operating through Hermes Agent, with Mico as owner and final approver. Start here:

- **`AGENTS.md`** — how any agent working in this repo operates: rules, roles, evidence standard.
- **`docs/DECISIONS.md`** — open decisions Mico needs to make, with real options and trade-offs.
- **`tasks/BOARD.md`** — current work.
- **`hermes/PROFILE.md`** — one-time setup for the Hermes profile that runs this repo.
- **`references/plan/initial-plan.md`** — the original project plan.

Zero budget. Free and open-source tools only.
