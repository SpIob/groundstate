# Groundstate

Groundstate is an AI-orchestrated pipeline that screens materials for efficient, theoretically grounded alternatives to current energy resources. Version 1, covering Li-ion battery cathodes, is under way. Everything the pipeline produces is a computed estimate used to narrow candidates, not an experimental result.

The pipeline runs locally on one laptop and sends its AI calls to free-tier APIs over the network. The project has a zero budget, so everything in it is free and open source.

Documentation is in `docs/`. The `references/` directory holds the project plan, method notes, and citation standard; start at `references/README.md`.
