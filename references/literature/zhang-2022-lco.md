## How it bears on the current task
Single open full-text source carrying consistent reference numbers for all three benchmark materials (Table 1), used as primary anchor for the benchmark-set table. Its "operating voltage" is a practical/operating figure, not a computed equilibrium voltage — the benchmark comparison in T-003 must treat it as an approximate reference (D-003 band ±0.2–0.3 V).
