## How it bears on the current task
Corroborates the LFP row (170 mAh·g−1, 3.4–3.45 V) used in the benchmark set. Treat 3.4 V as the same reference value as other reviews' 3.45 V plateau — same basis (vs. Li/Li+), rounding differs.
